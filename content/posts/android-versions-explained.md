<p>Google now releases major versions earlier in the year than it used to, followed by smaller feature drops. Phone makers add their own skins on top: One UI (Samsung), HyperOS (Xiaomi), OxygenOS (OnePlus) and others, so features and menu names vary.</p>

<h2>Version number vs security patch</h2>
<p>The version number brings new features. The <b>monthly security patch</b> fixes vulnerabilities, some of which are actively exploited. A phone on an older Android version but with recent patches is safer than one with a newer version and patches a year old.</p>

<h2>How long will my phone get updates?</h2>
<ul>
<li><b>Google Pixel 8 and newer</b> and recent <b>Samsung Galaxy S</b> flagships are promised seven years of OS and security updates.</li>
<li>Many mid-range phones get three to five years of security updates and fewer OS upgrades.</li>
<li>Budget phones sometimes get very little. Check the maker's published update policy before you buy.</li>
</ul>

<h2>How to update</h2>
<ol class="steps">
<li>Charge to at least 50% and connect to Wi-Fi.</li>
<li>Open <b>Settings › System › Software update</b> (or Settings › Software update on Samsung).</li>
<li>Also check <b>Google Play system update</b> under Settings › Security &amp; privacy: Google delivers some fixes this way, even to older phones.</li>
</ol>

<h2>What to do if your phone no longer gets updates</h2>
<ul>
<li>Keep apps updated through Google Play, avoid sideloading APKs, and keep Play Protect on.</li>
<li>Do not use it for banking if it is years past its last security patch.</li>
<li>Consider a newer model with a long update promise, or a refurbished Pixel.</li>
</ul>

<h2>Quick answers</h2>
<h3>Why did Google stop using dessert names?</h3>
<p>From Android 10 Google switched to plain numbers for clarity worldwide, though internal dessert codenames are still used by developers.</p>
<h3>Can I install a newer Android version myself?</h3>
<p>Only through official updates, unless you install a custom ROM, which is technical and can void warranties and break banking apps.</p>
<h3>Is my old Android phone safe to use?</h3>
<p>If its security patch is more than a year old, it is increasingly exposed. Limit sensitive use and plan an upgrade.</p>
