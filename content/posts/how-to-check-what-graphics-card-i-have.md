<h2>How to check what graphics card you have, in the right order</h2>
<p>The graphics card, also called the GPU or video card, is the part of your computer that draws everything on the screen. Knowing its exact name matters when you want to know whether a game will run, whether you can connect a second monitor, or what to type into a driver download page. Vague answers like &#x27;Intel graphics&#x27; are not enough, because Intel has made dozens of different versions.</p>
<p>There are several tools built into Windows that reveal this name, and they do not all give the same level of detail. Some show only the maker, while others show the full model. The order below starts with the one that gives the clearest answer fastest, then moves to methods that confirm it or fill in gaps.</p>
<p>Use Task Manager first for the full model name. Use Device Manager or the DirectX Diagnostic Tool if you want a second opinion or Task Manager shows something unusual. On a laptop, expect to see two GPUs and read the dedicated section further down. Only open the case if software leaves you genuinely unsure.</p>

<h2>Task Manager first: the fastest route on Windows 10 and 11</h2>
<p>Task Manager has been able to show GPU details since Windows 10, and the same steps work on Windows 11. Press Ctrl+Shift+Esc together. If the window that opens is small and has no tabs, click &#x27;More details&#x27; at the bottom to expand it. Then click the Performance tab, which shows graphs for CPU, Memory and other parts.</p>
<p>In the left-hand list of that Performance tab, scroll down until you see GPU. Click it. The name of your graphics card appears in large text in the top-right corner, for example &#x27;GPU 0 - NVIDIA GeForce RTX 3060&#x27;. Below it you will see useful extras: the driver version and date, the amount of dedicated video memory, and a live graph of how hard the GPU is currently working.</p>
<p>If your laptop has two graphics chips, Task Manager lists them separately, as GPU 0 and GPU 1. Usually GPU 0 is the integrated Intel or AMD chip that saves battery, and GPU 1 is the dedicated NVIDIA or AMD card used for games and heavy work. The list order is not guaranteed, so look at the names rather than the numbers.</p>
<p>One caveat: Task Manager needs a working display driver to show all this. If it only shows &#x27;GPU 0&#x27; with no proper name, the driver is missing or broken, and the next section&#x27;s methods will help you identify the hardware itself.</p>
<div class="note"><b>Tip:</b> Right-click the taskbar and choose Task Manager if the keyboard shortcut does not work.</div>
<h3>What the GPU graph in Task Manager means</h3>
<p>The big graph under the name is GPU use, the percentage of the card&#x27;s processing capacity in use right now. On a quiet desktop it should sit near zero. When a game runs, it should climb high, often above 90 percent. If it stays near zero while a game stutters, the game may be running on the other GPU or the driver may have a problem.</p>
<h2>Confirm it with Device Manager and the DirectX Diagnostic Tool</h2>
<p>Task Manager is fast, but two built-in tools give you a second opinion and extra details. Both work the same on Windows 10 and Windows 11, and neither needs an internet connection.</p>
<p>Device Manager lists every piece of hardware Windows can see. Press the Windows key and X together, then click Device Manager. Expand the section called &#x27;Display adapters&#x27;. Every graphics chip in the machine appears there, by full name. This view is also the place to check driver health: a small yellow warning triangle next to a name means the driver has a problem. Right-click any entry and choose Properties for more detail.</p>
<p>The DirectX Diagnostic Tool, known as dxdiag, reports deeper information, including the exact driver version and its release date. Press the Windows key and R together to open the Run box, type dxdiag, and press Enter. Click the Display tab (or the Render tabs if there are several). You will see the maker, the chip name, the driver version and how much video memory it reports.</p>
<p>A telling result in either tool is &#x27;Microsoft Basic Display Adapter&#x27;. That is not a real graphics card; it is Windows saying it cannot identify the hardware or lacks a driver for it. Your PC still works, but slowly and often at the wrong screen resolution. The fix is to install the proper driver from the maker of your laptop or card.</p>
<ol class="steps"><li>Press Windows+R, type dxdiag, press Enter, and wait for the tool to load.</li><li>Click the Display tab, or each Render tab in turn on a laptop with two GPUs.</li><li>Note the Name, Manufacturer, Driver Version and Display Memory lines.</li><li>Type dxdiag again anytime you update a driver, to confirm the version changed.</li></ol>

<h2>A laptop with two GPUs: which one is actually being used?</h2>
<p>Almost every gaming or workstation laptop sold in recent years contains two graphics processors. The integrated GPU, built into the Intel or AMD processor, handles everyday work and sips power so the battery lasts. The dedicated GPU, a separate NVIDIA GeForce or AMD Radeon chip, handles games and heavy tasks but drains the battery quickly. Windows is supposed to switch between them automatically.</p>
<p>To see which chip is running a particular program, open Task Manager, go to the Performance tab, and select each GPU in turn. Then start the program in question. Watch which GPU&#x27;s graph jumps. On Windows 10 and 11 you can also open the Processes tab, right-click the column headings, choose Select columns, and tick GPU and GPU engine to see per-program usage directly.</p>
<p>If a game runs on the wrong chip, you can set it manually. On Windows 11, go to Settings &gt; System &gt; Display &gt; Graphics, add the program, choose Options, and pick High performance. On Windows 10 the same setting lives at Settings &gt; System &gt; Display &gt; Graphics settings. NVIDIA laptop owners can also right-click the desktop, open the NVIDIA Control Panel, and use Manage 3D settings.</p>
<p>A common laptop mistake is assuming the dedicated GPU is broken because the graphics look weak. Often the game is simply running on the integrated chip. Check Task Manager before you panic, and remember that all of this is irrelevant when running on battery in a power-saving mode, where Windows deliberately favours the small chip.</p>

<h2>Looking inside the desktop when software is inconclusive</h2>
<p>Software identifies a graphics card almost every time, but there are edge cases: a freshly built PC with no driver installed, a second-hand PC with a heavily modified system, or a card so old that modern Windows labels it generically. In those situations the card itself tells the truth.</p>
<p>Shut down the PC completely and switch off the power supply at the back. Unplug the cable, take off the side panel, and look at the largest circuit board standing upright in the slots near the middle of the motherboard. The model name is printed on it in large letters, often on the fan shroud or along the top edge. GeForce, Radeon and the model number are usually obvious.</p>
<p>Two physical details help if the label is worn. A large card that occupies two or three slot-widths and needs one or two thick cables from the power supply is a modern dedicated card. A small board, or graphics built directly into the motherboard with no separate card at all, means integrated graphics. Photograph the card with your phone before closing the case, so you have the name for the driver download page later.</p>
<p>Standard precautions apply: avoid touching components on the boards, ground yourself by touching the metal case first, and never work inside a PC with the power connected. If the card has cables running to it from the power supply, leave those connected unless you need to remove the card itself.</p>
<div class="note warn"><b>Common mistake:</b> Never open a PC while the power cable is connected; switch off the PSU switch at the back first.</div>
<h2>Checking performance: is your graphics card actually doing its job?</h2>
<p>Knowing the name is half the answer; the other half is whether the card performs as it should. Three easy checks cover this, from casual to thorough, and none requires buying anything.</p>
<p>Start with Task Manager. Open the Performance tab, select the GPU you expect to be working, and run your usual game or video edit. The use graph should climb sharply, and dedicated GPU memory should be in use. A healthy card in a game typically sits above 80 or 90 percent use. If it barely moves while the game stutters, the game is probably running on the integrated GPU, which the laptop section above helps you fix.</p>
<p>Next, watch the frame rate, or FPS, which counts how many images per second the card delivers. Many games have a built-in FPS counter in their video or display settings; the Steam client can also show one. Compare what you get against published results for your card at your screen resolution. A card performing far below its normal numbers may be overheating, throttling, or running an old driver.</p>
<p>For a proper test, use a free benchmark such as 3DMark&#x27;s basic edition or the Unigine Heaven and Valley demos. These run a fixed 3D scene and score your card, and you can compare that score online with the same model. Run one before and after updating drivers or cleaning dust from the fans, and the score change tells you whether you fixed a real problem. Expect scores to drop noticeably if the laptop is on battery power rather than plugged in.</p>

<h2>Quick answers</h2>
<h3>Why does Task Manager show two GPUs on my laptop?</h3>
<p>Laptops with a dedicated graphics chip have two: an integrated Intel or AMD one for everyday work and battery life, and a separate NVIDIA or AMD one for games. Windows lists both, and switches between them depending on the program.</p>
<h3>What does Microsoft Basic Display Adapter mean?</h3>
<p>It means Windows could not identify your graphics hardware or has no driver for it, so it uses a generic fallback. Install the correct driver from your laptop or card maker&#x27;s website to fix it.</p>
<h3>Does dxdiag work on Windows 11?</h3>
<p>Yes. The DirectX Diagnostic Tool has been part of Windows for many years and works the same on Windows 10 and 11. Press Windows+R, type dxdiag, and check the Display or Render tabs.</p>
<h3>How do I know if my graphics card is failing?</h3>
<p>Common signs are screen glitches, coloured artefacts, crashes during games, and benchmark scores far below other results for the same model. Overheating from dust is often the cause, so clean the fans before assuming the card is dead.</p>
<h3>Can I check the graphics card on a Mac or Chromebook?</h3>
<p>On a Mac, click the Apple menu and choose About This Mac to see the chip name. Chromebooks use integrated graphics and do not name the chip in settings, but the manufacturer&#x27;s specifications page for your exact model lists it.</p>
