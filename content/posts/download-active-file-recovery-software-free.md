<div class="key"><b>Do this first:</b> stop using the drive that held the file. Every new file you save, app you install or update that runs can overwrite the space where the deleted file still sits. Then work through the steps below in order, from easiest to most technical.</div>

<h2>Why deleted files can often be recovered</h2>
<p>When you delete a file, the file system usually just marks its space as free; the data stays until something new is written over it. That is why recovery tools can find files on hard drives, USB sticks and memory cards. It is also why speed matters.</p>
<p><b>SSDs are different.</b> Most SSDs use a feature called TRIM, which tells the drive to actually erase freed blocks soon after deletion to keep it fast. On an internal SSD with TRIM on (the default on Windows and macOS), recovery tools often find nothing. Backups and version history are your best hope there.</p>

<h2>Step 1: Check the places files hide</h2>
<ul>
<li><b>Recycle Bin / Trash</b>, including the cloud versions: OneDrive, Google Drive and Dropbox all keep deleted files for a period (often around 30 days).</li>
<li><b>Previous versions:</b> on Windows, right-click the folder › Properties › Previous Versions (works if File History or restore points are on).</li>
<li><b>Time Machine</b> on a Mac: open the folder, then enter Time Machine and go back in time.</li>
<li><b>Phone photos:</b> Google Photos and the iPhone Photos app have a "Recently deleted" album.</li>
</ul>

<h2>Step 2: Use a trustworthy free recovery tool</h2>
<p>Install recovery software on a <b>different</b> drive from the one you are recovering, and save recovered files to a different drive too.</p>
<table><thead><tr><th>Tool</th><th>Platforms</th><th>Good to know</th></tr></thead><tbody>
<tr><td>Windows File Recovery</td><td>Windows 10/11</td><td>Free from Microsoft, command line only. Works on hard drives, USB and SD cards.</td></tr>
<tr><td>PhotoRec + TestDisk</td><td>Windows, macOS, Linux</td><td>Free and open source. PhotoRec recovers hundreds of file types; TestDisk can repair lost partitions. Text interface, but very capable.</td></tr>
<tr><td>Recuva</td><td>Windows</td><td>Long-standing free tool with a simple wizard. Fine for quick jobs on hard drives and memory cards.</td></tr>
</tbody></table>
<p>Many "free" recovery apps scan for free and then ask for payment before saving anything. That is not a scam, but check before you invest time. Only download recovery tools from the developer's official site; fake recovery apps are a common way to spread malware.</p>

<h2>Step 3: Memory cards and USB sticks</h2>
<p>Do not format the card, even if the camera or phone asks you to. Plug it into a computer with a card reader and run PhotoRec or Recuva against it. If the card is not detected at all, try another reader and port before assuming it has failed.</p>

<h2>When to stop and call a professional</h2>
<ul>
<li>The drive clicks, buzzes or is not detected at all.</li>
<li>It was dropped or got wet.</li>
<li>The data is irreplaceable and the first free attempt failed.</li>
</ul>
<p>Running software on a physically failing drive can destroy what is left. Data recovery labs open drives in clean rooms; it is expensive, but it is the only option for mechanical failure.</p>

<h2>Quick answers</h2>
<h3>Can I recover files after emptying the Recycle Bin?</h3>
<p>Often yes on hard drives and memory cards, if you act quickly and stop writing to the drive. On SSDs with TRIM, usually not.</p>
<h3>Can I recover files after formatting?</h3>
<p>A quick format leaves most data in place, so tools like PhotoRec can often find it. A full format on modern Windows writes zeros over the drive, which makes recovery practically impossible.</p>
<h3>Is free recovery software safe?</h3>
<p>The tools listed above are well-known. The risk is fake look-alikes: download only from official sites.</p>
